关于 DN42 Search

项目简介

DN42 Search 是一个专为 dn42 去中心化网络 设计的开源搜索引擎。它借鉴了 Google 等主流搜索引擎的核心技术架构， 包括网络爬虫、倒排索引、BM25 排序算法和 PageRank 链接分析。

技术架构

1. 网络爬虫 (Web Crawler)

  • 基于 asyncio + aiohttp 的异步并发爬虫
  • URL Frontier 双队列架构（优先级队列 + 每主机礼貌队列）
  • 支持 robots.txt 协议和爬取延迟控制
  • 内容去重（SHA-256 哈希）和 URL 去重
  • 严格限制爬取范围为 dn42 网络（172.20.0.0/14, fd00::/8, *.dn42）

2. 倒排索引 (Inverted Index)

  • 自研倒排索引引擎，支持内存和磁盘持久化
  • 可变字节编码（Variable Byte Encoding）压缩倒排列表
  • 多字段索引（标题、URL、正文、标题标签）
  • 支持字段权重配置

3. 排序算法 (Ranking)

  • BM25：概率检索模型，考虑词频饱和和文档长度归一化
  • PageRank：基于链接图的权威度计算，使用幂迭代法求解
  • 混合排序：综合相关性得分和权威度得分

4. 查询处理 (Query Processing)

  • 拼写检查与自动修正（基于编辑距离 + 语言模型）
  • 查询意图分类（导航型/信息型/事务型）
  • 支持高级搜索语法（site:, title: 等）

DN42 网络

dn42（Decentralized Network 42）是一个大型的动态 VPN 网络， 采用真实互联网技术构建——包括 BGP 路由协议、whois 数据库、DNS 系统等。 参与者通过网络隧道（WireGuard、OpenVPN 等）相互连接， 并通过边界网关协议（BGP）交换路由信息。

  • 规模：1500+ 自治系统，1700+ 路由前缀
  • IPv4：172.20.0.0/14
  • IPv6：fd00::/8 (ULA)
  • ASN：4242420000-4242429999
